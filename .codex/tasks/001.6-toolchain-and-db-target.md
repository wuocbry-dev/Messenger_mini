3. IDENTIFY THE EXACT MYSQL INSTANCE
==================================================

Do NOT only report the schema name.

Using the SAME database configuration loaded by Spring Boot/backend/.env,
execute read-only queries that identify the exact MySQL server:

SELECT DATABASE();

SELECT @@hostname AS hostname;

SELECT @@port AS port;

SELECT @@server_uuid AS server_uuid;

SELECT CURRENT_USER() AS current_user;

SELECT @@version AS mysql_version;

SELECT @@datadir AS data_directory;

Also report the JDBC target WITHOUT password:

- DB host
- DB port
- DB name
